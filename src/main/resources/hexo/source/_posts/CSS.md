## 定义

层叠样式表，是一种样式表语言，用来描述HTML文档的呈现(美化内容)

书写位置：title标签下方添加style双标签，style标签里面书写CSS代码

```html
<head>
    <title>CSS</title>
    <style>
        p{
            color:red;
        }
    </style>
</head>
<body>
    <p>体验CSS</p>
</body>
```

CSS注释是/*   */

color调整颜色

font-size：字体大小

属性名和属性值一起出现俗称键值对

书写规则

选择器{属性名:属性值}

## 引入方式

- 内部样式表：学习使用

  - CSS代码写在style标签里面

- 外部样式表：开发使用

  - CSS代码写在单独的CSS文件中(.css)

  - 在HTML使用link标签引入

    ```html
    <link rel="stylesheet" href="URL">
    ```

- 行内样式：配合js使用

  - CSS写在标签的style属性值里

    ```html
    <div style="color:red;font-size:20px;">这是div标签</div>
    ```

### 标签选择器

定义：使用标签名作为选择器，选择同名标签设置相同样式

### 类选择器

作用：查找标签，差异化设置标签的显示效果

步骤：

- 定义类选择器：  .类名
- 使用类选择器：  标签添加class="类名"

一个标签可以多个类名，类名用空格隔开

开发习惯：类名自定义，见名知义，多个单词用-连接

### id选择器

作用：查找标签，差异化设置标签的样式

场景：id选择器一般配合js使用，很少用来设置css样式

步骤：

- 定义id选择器：  #id名
- 使用id选择器： 标签添加id="id名"

规则：

- 同一个id选择器在一个页面只能使用一次

### 通配符选择器

作用：查找页面所以标签，设置相同样式

通配符选择器：  *，不需要调用，浏览器自动查找页面所以标签，设置相同样式

```css
* {
    color:red;
}
```

## 符号选择器

定义：由两个或多个基础选择器，通过不同的方式组合而成

作用：更准确、更高效的选择目标元素（标签）

### 后代选择器

定义：选中某元素的后代元素

写法：父选择器  子选择器{CSS属性}   父子选择器之间用空格隔开

### 子代选择器

选择某元素的子代选择器(最近的子段)

格式：父选择器>子选择器

### 并集选择器

选择多组标签设置相同的样式

格式：选择器1，选择器2，选择器3，选择器N{CSS属性}  

### 交集选择器(了解)

选中同时满足多个条件的元素

格式：选择器1选择器2{CSS属性}，选择器之间连写

注意：标签选择器要写在最前面

### 伪类选择器

伪类表示元素状态，选中元素的某个状态设置样式

鼠标悬停状态：选择器:hover{CSS属性值}

扩展：

| 选择器   | 作用         |
| -------- | ------------ |
| :link    | 访问前       |
| :visited | 访问后       |
| :hover   | 鼠标悬停     |
| :active  | 点击时(激活) |

提示：如果要给超链接设置以上四种状态，需要按照LVHA的顺序书写

## CSS三大特性

### 继承性

定义：子级默认继承父级的文字控制属性

当标签有自己的样式就不会继承父级的样式

### 层叠性

- 相同属性会覆盖：后面CSS属性覆盖前面的CSS属性
- 不同属性会叠加：不同的CSS属性都生效

### 优先级

定义：也叫权重，当一个标签使用了多种选择器时，基于不同种类的选择器的匹配规则

公式：通配符选择器<标签选择器<类选择器<id选择器<行内选择器<!important(提权功能，提到最高，加在分号前面)

(选中标签范围越大，优先级越低)

## 叠加计算规则

定义：如果是复合选择器，则需要权重叠加计算

公司：（每一级之间不存在进位）

(行内样式，id选择器个数，类选择器个数，标签选择器个数)

格则

- 从左向右依次比较个数，同一级个数较多的优先级高，如果个数相同，则向后比较
- !important权重最高
- 继承权重最低(右！important也是最低)

### 边框线

属性名：border（bd）

属性值：边框线粗细 线条样式 颜色（不区分顺序）

| ------ | -------- |

设置单向边框线

写法：border-方位名词(bd+方位首字母，例如bdl)

属性值：边框粗细 线条样式 颜色(不区分顺序)

### 内边距

作用：设置内容与盒子边缘之间的距离

属性名：padding/padding-方位名词

#### 多值写法

padding多值写法

| 取值个数 | 示例                         | 含义               |
| -------- | ---------------------------- | ------------------ |
| 一个     | padding：10px                | 四个内边距均为10px |
| 四       | padding：10px 20px 40px 80px | 上右下左           |
| 三       | padding:    10px 40px 80px   | 上左右下           |
| 二       | padding:1-px 80px            | 上下左右           |

从上开始顺时针，没数值根对面一样

### 尺寸计算

- 默认情况

  盒子尺寸=内容尺寸+border尺寸+内边距尺寸

- 结论：给盒子加border/padding会撑大盒子

- 解决：

  - 手动做减法，剪掉border/padding的尺寸
  - 内减模式：box-sizing：bordder-box

### 外边距

作用：拉开两个盒子之间的距离

属性名：margin

提示：与padding写法和含义相同

细节：不会撑大盒子

属性值有个auto可以居中，但是盒子要有宽度才可以居中

## 外边距合并现象

场景：垂直排列的兄弟元素，上下margin会合并

现象：取两个margin中的较大值生效

## 外边距塌陷问题

场景：父子级的标签，子级的添加上外边距会产生塌陷问题

现象：导致父级一起向下移动

解决办法：

- 取消子级margin，父级别设置padding
- 父级设置overflow：hidden
- 父级设置border-top

## 行内元素—内外边距问题

解决方法：给行内元素添加line-height可以改变垂直位置

## 浮动

作用：让块元素水平排列

属性名：float

属性值

- left：左对齐
- right：右对齐

浮动后特点：

- 具备行内块模式特点
- 顶对齐
- 浮动的盒子会脱离标准流

### 清除浮动

场景：浮动元素会脱标，如果父级没有高度，子级无法撑开父级高度(可能导致页面布局错乱)

解决办法：清除浮动(清除浮动带来的影响)

方法一：额外标签法

- 在父元素内容的最后添加一个块级元素，设置CSS属性clear：both（同意CSS命名为clearfix）

方法二：单伪元素法

```css
单伪元素法
.clearfix::after{
  content: "";
  display: block;
  clear: both;
}
双伪元素法
.clearfix::before,(before解决塌陷问题的)
.clearfix::after{
  content: "";
  display: block;
}
.clearfix::after{
  clear: both;
}
```

推荐用双伪元素法

overflow

- 父元素添加CSS属性overflow:hidden

## Flex布局

定义：也叫弹性布局，是浏览器提倡的布局模式，非常适合结构化布局，提供了强大的空间分布和对齐能力

Flex模型不会产生浮动布局中脱标现象，布局网页更简单、更灵活

### 组成

设置方式：给父元素设置display：flex，子元素可以自动挤压或拉伸

组成部分

- 弹性容器
  - 弹性盒子(沿着主轴方向排列)
  - 主轴：默认在水平方向
  - 侧轴/交叉轴：默认在垂直方向

## 定位

作用：灵活的改变盒子在网页中的位置

实现：

1. 定位模式：position
2. 边偏移：设置盒子的位置

- left
- right
- top
- bottom

### 相对定位

position：relative

特点：

1. 改变位置参照物是自己原来的位置
2. 不脱标，占位
3. 标签显示模式特点不变

### 绝对定位

position：absolute

使用场景：子级绝对定位，父级相对定位（子绝父相）

特点

1. 脱标，不占位
2. 参照物：先找最近的已经定位的祖先元素：如果所有祖先元素都没有定位，参照浏览器可视区该位置
3. 显示模式特点改变：宽高生效(具备了行内块的特点)

### 定位居中

实现步骤：

1. 绝对定位
2. 水平、垂直边偏移为50%
3. 子级向左、上移动自身尺寸的一半
   - 左、上的外边距为-尺寸的一半
   - transform：translate(-50%，-50%)

### 固定定位

position：flexd

场景：元素的位置在网页滚动时不会改变

特点：

1. 脱标，不占位
2. 参照物：浏览器窗口
3. 显示模式特点：具备行内块特点

### 堆叠层级z-index

默认效果：按照标签书写顺序，后来者居上

作用：设置定位元素的层级顺序，改变定位元素的显示顺序

取值是整数，默认值是0，取值越大默认值月靠上

## CSS精灵

定义：CSS精灵，也叫CSS Sprites（也叫CSS雪碧），是一种网页图片应用处理方式，把网页中一些背景图片整合到一张图片文件夹中，

再background-position精确的定位出背景图片的位置

优点：减少服务器被请求次数，减轻服务器的压力，提高页面加载速度

### 实现步骤：

1. 创建盒子，盒子尺寸与小图尺寸相同
2. 设置盒子背景图为经历图
3. 添加background-position属性，改变背景图位置
   1. 使用PxCook测量小图片左上角坐标
   2. 取负数坐标为background-position属性值（向左上移动图片位置）
